# Security

## Reporting a vulnerability

Use GitHub's private [Report a vulnerability](https://github.com/Kensa-Health/spc-lib-py/security/advisories/new)
form. Include the affected version, a minimal reproduction with synthetic data, the impact and
any suggested mitigation. Do not disclose vulnerabilities or sensitive data in public issues.

If the private form is unavailable, email [opensource@kensahealth.com](mailto:opensource@kensahealth.com)
with a short description and we will arrange a private route for the details. Do not open a
public issue.

## Supported versions

During 0.x development, security fixes target the latest released version. There is no guaranteed
response time or long-term support commitment. Ordinary numerical bugs can be reported in issues
using synthetic data; use the private route when a bug has a security impact.
