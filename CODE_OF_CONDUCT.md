# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to issues, pull requests, Discussions and any other project space.

In short: be respectful, keep feedback about the work, and do not harass, insult or
discriminate against anyone. Do not post patient data, confidential data or anyone's
personal information.

## Reporting

Email [opensource@kensahealth.com](mailto:opensource@kensahealth.com), or use GitHub's
**Report content** option on the comment, issue or discussion concerned. Maintainers at
Kensa Health Virtual Care Ltd review reports, keep the reporter's identity private and may
edit or remove content, or block accounts, that breach this code.
