# Golden parity fixtures

The two committed CSVs in `nhsrdatasets/` were generated by the R package
[NHSRplotthedots 0.2.2](https://github.com/nhs-r-community/NHSRplotthedots/tree/050b07d7eacc011767532732f69b8fd7d6a28fd3)
from its exact release commit `050b07d7eacc011767532732f69b8fd7d6a28fd3`.
They are independent reference outputs, not values calculated by this Python library.

## Input and checks

Both use organisation `RJZ`, type `1`, for 36 months from April 2016 to March 2019:

- `ae_attendances_rjz_type1_xmr_expected.csv`: attendances, neutral improvement direction.
- `ae_attendances_rjz_type1_breaches_xmr_expected.csv`: breaches, decreasing is improvement.

The R input is NHSRdatasets v0.3.3, pinned to commit
`defefde0927c189c81e2322a85be189c78f30686`, file `data/ae_attendances.rda`.
The Python tests load the existing parquet snapshot; matching dates and values verifies
that both input subsets agree. See [dataset provenance](nhsrdatasets/PROVENANCE.md).

`tests/test_parity_xmr.py` compares all 72 points by date: input values, mean, UCL/LCL,
outside-limit flags, selected rule and point classification. Numeric tolerance is
relative `1e-12` / absolute `1e-9`, allowing for CSV decimal precision. R's descriptive
rule labels are mapped explicitly to Python rule identifiers; unknown labels fail.
The breaches fixture exercises all four rules as well as common-cause points.

Scope: whole-segment XmR limits, single-pass outlier screening and default seven-point
rules. These fixtures do not establish parity for other chart kinds, every option,
rebasing, short segments or the optional autocorrelation adjustment. Those paths have
separate unit, property and differential tests. No R installation or network is needed
for the normal Python test suite.

## Regeneration

Run the setup and commands in `scripts/generate_r_golden_output.R` from the repository
root. Install the exact reference commit and use the pinned input URL in its header.
The script refuses a different package version and writes both CSVs. Review the diff,
then run `python -m pytest tests/test_parity_xmr.py`. Do not replace expected values with
Python output or regenerate them just to accept a regression.
